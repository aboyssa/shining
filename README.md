Shining Management System

نبذة عن المشروع

نظام متكامل لإدارة سيرفرات GTA V Roleplay، يركز على إدارة اللاعبين والصلاحيات والعمليات الإدارية من خلال واجهة موحدة.

أبرز المزايا

نظام تسجيل دخول ومصادقة متكامل.

ربط الحسابات عبر Discord OAuth.

نظام صلاحيات متعدد المستويات.

إدارة اللاعبين والملفات الشخصية.

لوحة تحكم خاصة بالإدارة.

نظام متكامل لإدارة التذاكر والبلاغات.

إدارة الرتب والصلاحيات الإدارية.

نظام وظائف وإحصائيات للاعبين.

متجر وخدمات خاصة باللاعبين.

حماية صفحات وميزات الإدارة من الوصول غير المصرح به.


التقنيات المستخدمة

Frontend: React, TypeScript

Backend: Node.js

Authentication: Discord OAuth

Database: نظام قاعدة بيانات متكامل لإدارة المستخدمين والصلاحيات

Security: تشفير كلمات المرور باستخدام bcrypt ونظام صلاحيات متعدد المستويات.


هيكل النظام

ينقسم المشروع إلى عدة أجزاء رئيسية تشمل الخادم الخلفي، واجهة المستخدم، نظام المصادقة، لوحة الإدارة، لوحة اللاعبين، ونظام إدارة التذاكر والصلاحيات.

الصلاحيات

يتضمن النظام عدة مستويات إدارية:

Player: الصلاحيات الأساسية.

Staff: إدارة التذاكر والبلاغات.

Manager: إدارة الطاقم والإحصائيات.

Co-Leader: إدارة الأدوار والصلاحيات.

Leader: صلاحيات إدارية كاملة.
